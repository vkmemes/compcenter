# Комплексный план автоматизации Компьютерного Центра (КЦ)

**Инфраструктура:** 500 ПК (Windows 10/11) в домене Active Directory (`ygk.ru`).  
**Режим входа:** Беспарольный профиль «Гость», собираемый на лету из `C:\Users\Default`.  
**Главные цели:** Высокая отказоустойчивость, минимизация ручного труда сисадминов, фоновое управление без срыва занятий.

---

## 1. Замена LiteManager: Отказоустойчивый кластер MeshCentral (В плане)

### 1.1. Архитектура и отказоустойчивость
- **Серверный кластер (Active-Active):** 2 легковесные виртуальные машины под управлением Linux (Ubuntu Server / Debian).
- **Балансировка и плавающий IP:** Использование `Keepalived` (VRRP) + `HAProxy` для единого виртуального адреса (например, `mesh.ygk.ru` / `192.168.x.x`). При падении одной ноды переключение происходит за 1 секунду без разрыва сессий.
- **База данных:** Репликация состояний (MongoDB Replica Set или MariaDB).
- **100% Local Air-Gap:** Полная автономность внутри сети колледжа (работает даже при отключении внешнего интернета).

### 1.2. Функционал агента на 500 ПК
- **Фоновый терминал:** Доступ к PowerShell / CMD в фоне без ведома пользователя и перехвата рабочего стола.
- **Фоновый проводник:** Загрузка/выгрузка файлов, правка конфигов без разрыва сессии студента.
- **Smart Wake-on-LAN (WOL Relay):** Автоматическая побудка выключенных ПК аудитории через соседей по классу (обход изоляции VLAN).
- **Инвентаризация на лету:** Отображение объема свободной памяти, остатка места на SSD, времени аптайма, IP/MAC.
- **Массовый запуск сценариев:** Запуск PowerShell-команд одновременно на всю аудиторию или весь колледж в 1 клик с таблицей результатов.

## 2. Модульный репозиторий и Билдер скриптов тихой установки ПО (Package Builder)
- **Универсальный генератор установщиков (Package Builder):**
  - Создание стандартизированных сценариев установки `Install-<App>.ps1` по единому 6-этапному шаблону:
    1. *Kill Processes:* принудительное закрытие зависших процессов приложения.
    2. *Clean Old Versions:* поиск в реестре `Uninstall` и чистка предыдущих релизов.
    3. *Silent Setup:* запуск тихой установки с автоматической поддержкой флагов (MSI, InnoSetup, NSIS, InstallShield, АСКОН, Autodesk).
    4. *License Injection:* интеграция с серверами лицензий колледжа (HASP/Sentinel `hasp_*.ini`, FlexNet `ADSKFLEX_...`, Guardant, ключи реестра).
    5. *Default User & Active Setup:* прописка настроек и лицензий в шаблон `C:\Users\Default` и `Active Setup` для мгновенной готовности у любого студента-гостя.
    6. *Verification & Logging:* проверка кодов завершения (ExitCode 0 / 3010) и запись логов в `C:\Windows\Temp\<App>_Install.log`.
- **Декларативные манифесты (`package.json`):**
  - Каждое приложение на сетевой шаре `\\server\distribs$\<App>` описывается простым JSON-манифестом (имя, процесс, ключи, лицензионный сервер).
- **Интеграция с GUI-панелью:**
  - Возможность выбора аудиторий и пакетов для раскатки в один клик через веб-селектор или MeshCentral.

## 3. Архитектура шаблона «Default User» и взаимодействие «Студент-Преподаватель»
- **Сетевой Drop Box («Сдать работу»):**
  - Развертывание ярлыка на Рабочем столе студента на сетевую шару `\\teacher-pc\DropBox$`.
  - Специфические права NTFS: студенты могут создавать файлы/записывать данные, но не имеют права на чтение содержимого папки и удаление (невозможно списать у одногруппника или удалить чужую работу).
- **Раздача материалов («Материалы к уроку»):**
  - Ярлык на шару `\\teacher-pc\Materials$` с правами Read-Only для быстрой раздачи методичек, ТЗ и заготовок чертежей.
- **Локальный Scratchpad («Мои проекты на Диске D» / `D:\Работы`):**
  - Ярлык на `D:\Работы` для сохранения тяжелых проектов САПР/3D, защищенных от сброса при пересоздании профиля «Гость».
  - **Защита от вредительства и случайного удаления (NTFS ACL):**
    - На папку `D:\Работы` накладываются специальные права: студентам разрешено создание файлов, создание папок и запись данных, но **не выдаются права на удаление (`Delete`) и удаление вложенных объектов (`DeleteSubdirectoriesAndFiles`)**.
    - В Windows NTFS запрет на удаление **автоматически блокирует и переименование файлов/папок** (в ОС переименование расценивается как удаление старого имени).
    - Результат: студент может создать папку со своей фамилией и сохранять проекты, но ни один одногруппник не сможет стереть или переименовать чужую работу. Полный доступ на удаление и наведение порядка остается только у Администраторов КЦ.
- **Твики реестра в `NTUSER.DAT`:**
  - Отключение окон первого запуска (First Run Wizard) в браузерах Edge / Chrome / Яндекс.
  - Предустановленные закладки на СДО Moodle, портал и расписание занятий колледжа.
  - Ассоциация расширений САПР-файлов (`.rnp`, `.cdw`, `.blend`).

## 4. Сетевая автоустановка и быстрое восстановление (PXE / Multicast FOG Project)
- **Золотой образ (Golden Image) в VM:**
  - Подготовка и поддержание эталонного образа в Hyper-V / Proxmox со всеми САПР и обновлениями.
  - Обобщение через `Sysprep` с файлом ответов `unattend.xml` (автоматическая генерация SID и активация).
- **Multicast-заливка за 12 минут:**
  - Раскатка образа одновременно на 30 ПК аудитории через FOG Project по UDP Multicast без перегрузки сети.
- **Авто-именование и привязка к розеткам:**
  - Жесткая привязка MAC-адреса ПК к номеру аудитории и розетки (`B309-PC01` ... `B309-PC30`).
  - Служба FOG автоматически меняет имя машины и вводит в правильную `OU` Active Directory `ygk.ru` при первой загрузке.

## 5. Мониторинг здоровья оборудования (Health Check)
- **Контроль остатка места на SSD:** Алерты при падении свободного места на `C:\` ниже 15–20 ГБ.
- **Контроль качества сети:** Детектирование просадки линка с 1 Гбит/с до 100 Мбит/с (выявление перебитых кабелей/розеток).
- **Контроль периферии:** Определение отключенных мышек и клавиатур по USB PnP ID.
- **SMART-мониторинг накопителей:** Предупреждение о деградации SSD до их полного отказа во время занятий.

---

## 6. Управление локальными учетными записями и безопасность (LAPS / PowerShell)
- Восстановление утерянного пароля встроенного администратора через централизованный ADSI-скрипт (поиск по SID `*-500`).
- Внедрение Microsoft LAPS для исключения ситуации с одинаковым паролем на всех 500 ПК (защита от несанкционированного доступа студентов).

---

## 7. Утренний чекап и оперативные оповещения (Telegram-бот КЦ)
- Автоматический сбор сводки в 08:00 утра перед первой парой: сколько ПК в сети, какие аудитории имеют проблемы с дисками или связью.
- Быстрые команды инженера прямо из чата (проверить класс, послать WOL, перезагрузить зависший ПК).
