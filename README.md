# Комплект скриптов автоматизации Renga Professional

Данный комплект предназначен для автоматического обновления **Renga Professional** на компьютерах учебных лабораторий/классов колледжа:
1. Принудительно завершает процессы Renga (`Renga.exe`, `AecApp.exe`).
2. Находит в реестре и чисто удаляет любые старые версии Renga в тихом режиме.
3. Устанавливает новую версию Renga Professional из `RengaProfessionalSetup.exe`.
4. Настраивает файл конфигурации `Settings.ini` и JSON-файлы:
   - Автоматически подставляет имя текущего компьютера (`$env:COMPUTERNAME`) в поле `CollaborationUserName`.
   - Прописывает сетевой сервер лицензий `v-as2.ygk.ru`.
   - Применяет настройки ко **всем существующим профилям** пользователей (`C:\Users\*`).
   - Применяет настройки в шаблон **Default User** и регистрирует **Active Setup**, чтобы любой новый студент/пользователь при первом входе сразу получал готовые настройки с лицензией.

---

## Структура файлов

- `Scan-DomainComputers.ps1` — сканер домена Active Directory (работает без RSAT): находит компьютеры, группирует их по классам/аудиториям, проверяет Ping/SMB и выгружает в `computers.txt`.
- `Deploy-RengaRemote.ps1` — скрипт централизованного удаленного запуска на компьютеры через WMI/SMB (C$) или WinRM.
- `Install-Renga.ps1` — главный рабочий скрипт (удаление старых версий, установка, настройка профилей).
- `Run-Install.bat` — лаунчер в один клик с автоматическим запросом прав Администратора.
- `computers.txt` — список компьютеров для удаленного развертывания.
- `RengaProfessionalSetup.exe` — дистрибутив новой версии Renga.
- `Renga Software\` — эталонные файлы конфигурации (`Settings.ini`, `gui_preferences.json` и др.).

## Шаг 1: Сканирование домена и выбор аудиторий

Скрипт подключается к домену `ygk.ru` через встроенный LDAP/ADSI (не требует установки RSAT):

```powershell
# 1. Посмотреть все аудитории колледжа и количество компьютеров в каждой:
.\Scan-DomainComputers.ps1

# 2. Проверить сетевую доступность конкретной аудитории (например, B309):
.\Scan-DomainComputers.ps1 -Classrooms "B309" -CheckOnline

# 3. Выгрузить нужные классы сразу в computers.txt:
.\Scan-DomainComputers.ps1 -Classrooms "B309", "B308", "B302", "B304", "B406", "B407" -Export

# 4. Либо выгрузить всё подразделение "Учебные" (124 ПК):
.\Scan-DomainComputers.ps1 -OU "OU=Учебные,OU=Компьютеры,DC=ygk,DC=ru" -Export
```

## Шаг 2: Удаленное развертывание

Скрипт `Deploy-RengaRemote.ps1` автоматически определяет доступность транспорта на целевых машинах:
- Если доступен **WinRM** (порт 5985) — использует `Invoke-Command`.
- Если WinRM закрыт (стандартная ситуация для рабочих станций) — использует **WMI (Win32_Process) + SMB C$**, который открыт и работает на всех ПК домена.

### Способы запуска:

**А) По списку аудиторий напрямую:**
```powershell
.\Deploy-RengaRemote.ps1 -Classrooms "B309", "B308" -ThrottleLimit 10
```

**Б) По файлу `computers.txt`:**
```powershell
.\Deploy-RengaRemote.ps1 -ComputerListFile ".\computers.txt" -ThrottleLimit 10
```

**В) По подразделению Active Directory (OU):**
```powershell
.\Deploy-RengaRemote.ps1 -TargetOU "OU=Учебные,OU=Компьютеры,DC=ygk,DC=ru" -ThrottleLimit 10
```

## Локальный запуск (с флешки или сети)

Если нужно запустить скрипт локально на ПК:
1. Запустите файл **`Run-Install.bat`** (он сам запросит повышение до Администратора).
2. Скрипт выполнит тихую деинсталляцию, установку и конфигурирование профилей.
3. Логи установки пишутся в `C:\Windows\Temp\Renga_Deploy.log`.
